One Wi-Fi network name, 29 characters, that tells a whole story: a baby
somehow changed the Wi-Fi password, and now nobody in the house can get
back online. A character, an event, and a household locked out — in the
few words a passer-by sees in a phone's network list.

The entry:

> **The Baby Changed the Password** (29 characters)

## Run it

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory for local runs). Deterministic: no network, no clock, no
randomness — the same entry, byte for byte, on every run.
